# huisvanvandaag.nl – GitHub Pages versie

Dit is een statische site die direct gehost kan worden via GitHub Pages.

## Publiceren via GitHub Pages

1. Maak een nieuwe repository aan op GitHub.
2. Upload alle bestanden uit deze map naar de root van die repository.
3. Ga in GitHub naar **Settings > Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Selecteer de branch `main` en folder `/root`.
6. Sla op. Na korte tijd staat de site live.

## Opmerking

- Het contactformulier en de nieuwsbrief zijn in deze versie visuele placeholders. Koppel later bijvoorbeeld Formspree, Basin of een andere formulierdienst.
- De site wordt nog sterker zodra je eigen foto's, Homey-flow screenshots en projectafbeeldingen toevoegt.
