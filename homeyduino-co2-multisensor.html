Bouw je eigen CO₂ multi-sensor met Homeyduino

Meet CO₂, temperatuur, luchtvochtigheid en licht met één zelfbouwsensor en gebruik die gegevens direct in Homey voor inzichten en slimme automatiseringen.

Categorie: DIY smart home Platform: Homey + Homeyduino Hardware: Wemos D1 Mini, MH-Z19B, DHT11 en LDR

Waarom dit project leuk én nuttig is

✓
Eén sensor, meerdere metingen
Je meet niet alleen CO₂, maar ook temperatuur, luchtvochtigheid en lichtsterkte in dezelfde opstelling.
✓
Betaalbaar zelf te bouwen
Met losse onderdelen bouw je deze multi-sensor voor een veel lager bedrag dan veel kant-en-klare CO₂ meters.
✓
Handig voor je binnenklimaat
Je krijgt beter zicht op ventilatie, luchtvochtigheid en de leefkwaliteit in huis.
✓
Direct bruikbaar in Homey
De metingen zijn te gebruiken in Homey Inzichten en als trigger voor flows.
✓
Mooi startpunt voor automatisering
Denk aan het automatisch aansturen van mechanische ventilatie wanneer de CO₂-waarde oploopt.

Wie slim wil ventileren, verwarmen of gewoon beter wil begrijpen wat er in huis gebeurt, heeft weinig aan losse metingen zonder context. Juist de combinatie van CO₂, temperatuur, luchtvochtigheid en licht geeft een veel completer beeld van je binnenklimaat.

In dit project bouw je daarom een betaalbare multi-sensor die meerdere waarden meet en die via Homeyduino direct aan Homey gekoppeld kan worden. Zo kun je met beperkte middelen zelf een praktische sensor maken die niet alleen meet, maar ook bruikbaar is in je dagelijkse automatiseringen.

Wat ga je bouwen?

Je bouwt een Homeyduino multi-sensor die vier metingen combineert in één project: CO₂, temperatuur, luchtvochtigheid en lichtsterkte. De sensor draait op een Wemos D1 Mini en gebruikt de MH-Z19B voor CO₂, een DHT11 voor temperatuur en luchtvochtigheid en een LDR voor lichtmeting.

  • Meten en monitoren → Je ziet het verloop van CO₂ en luchtvochtigheid terug in Homey Inzichten en kunt sneller beoordelen wanneer ventileren wenselijk is.
  • Automatiseren met flows → Je kunt de waarden gebruiken als trigger, bijvoorbeeld om mechanische ventilatie automatisch te starten bij een te hoge CO₂-concentratie.

Volgens de aangeleverde uitgangspunten ligt een acceptabel CO₂-niveau binnenshuis ergens tussen 600 en 800 ppm. Vanaf 1000 ppm is het wenselijk om te ventileren. Ook luchtvochtigheid speelt een grote rol: te droog en te vochtig kunnen allebei nadelige gevolgen hebben voor comfort, gezondheid en materialen in huis.

Benodigdheden

  • Microcontroller met WiFi en 5V: D1 Mini NodeMcu
  • MH-Z19B CO₂ sensor
  • DHT11 sensor
  • LDR sensor
  • Homey Smart Home HUB met de Homeyduino app geïnstalleerd

Stap-voor-stap uitleg

1. Sluit de sensoren aan

Begin met het aansluiten van de drie sensoren op de Wemos D1 Mini. In de broninformatie is het aansluitschema compact weergegeven. Daarbij wordt de DHT11 aangesloten op D4, de LDR op A0 en de MH-Z19B voor de CO₂-meting op D2. In de sketch staat daarnaast ook een UART-aansluiting opgenomen voor de CO₂ sensor, maar in dit project wordt de sensor uitgelezen via PWM.

  • DHT11 → D4
  • LDR sensor → A0
  • MH-Z19B CO₂ sensor → D2

2. Installeer de software die je nodig hebt

Voor het eenmalig configureren heb je een computer of laptop nodig met Arduino IDE, NodeMcu Flasher en Homeyduino. Zorg er in Arduino IDE voor dat je het juiste board selecteert voordat je de code uploadt.

3. Upload de code naar je Wemos D1 Mini

Onderstaande sketch maakt de sensor zichtbaar als Homeyduino-apparaat en stuurt waarden voor luchtvochtigheid, temperatuur, CO₂ en licht door naar Homey. In de WiFi-sectie vul je zelf je SSID en wachtwoord in. Volgens de broncode upload je de sketch op 9600 baud.

// Code for Homeyduino made by Smart Home Blog https://huisvanvandaag.nl. 
// Take a look at my site for more Homeyduino en other Smart Home projects.

#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <Homey.h>
#include <SimpleDHT.h>
#include <SoftwareSerial.h>
#include <MHZ.h>

#define PIN_DHT D4 // DHT11 
SimpleDHT11 dht11; // DHT11

#define CO2_IN D2 // D2 19 // Co2 
#define MH_Z19_RX D6  // Co2
#define MH_Z19_TX D5  // Co2 
MHZ co2(MH_Z19_RX, MH_Z19_TX, CO2_IN, MHZ19B); // Co2

unsigned long previousMillis = 0; // DHT11
const unsigned long interval = 10000; //Interval in milliseconds // DHT11

int LDRsensor = A0; // LDR

void wifi() {
  if (WiFi.status() != WL_CONNECTED) {
    WiFi.begin("<SSID>", "<PASSWORD>"); // Enter WiFi netwerk and password 
    uint8_t timeout = 30;
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
      if (timeout<1) break;
    }
    if (WiFi.status() == WL_CONNECTED) {
      //Print IP address
      Serial.print("Connected to WiFi! (");
      Serial.print(WiFi.localIP());
      Serial.println(")");
    }
  }
}

void setup() { // DHT11
  Serial.begin(9600);
  Homey.begin("LDR-DHT11-Co2 Multi-sensor");
  Homey.setClass("sensor");
  Homey.addCapability("measure_humidity"); // DHT11
  Homey.addCapability("measure_temperature");// DHT11
  Homey.addCapability("measure_co2"); // Co2 
  pinMode(CO2_IN, INPUT); // Co2
  Homey.addCapability("measure_luminance"); // LDR
}

  
 void  co2loop() { // void voor Co2
  wifi(); // Beide
  Homey.loop(); // Beide
  int ppm_pwm = co2.readCO2PWM();
  Serial.print("PPMpwm: ");
  Serial.print(ppm_pwm);
  Homey.setCapabilityValue("measure_co2", (int) ppm_pwm); 

Serial.println("\n------------------------------");
  delay(5000);
 }

void dhtloop() { // void voor DHT11
  wifi(); // Beide
  Homey.loop(); // Beide
   unsigned long currentMillis = millis(); // DHT11
  if(currentMillis - previousMillis > interval) { // DHT11
    previousMillis = currentMillis; // DHT11
    updateSensor(); // DHT11
  }
}

void updateSensor() { // DHT11
  byte temperature = 0; // DHT11
  byte humidity = 0; // DHT11
  int err = SimpleDHTErrSuccess; // DHT11
  if ((err = dht11.read(PIN_DHT, &temperature, &humidity, NULL)) != SimpleDHTErrSuccess) { // DHT11
    Serial.print("Read DHT11 failed, err="); Serial.println(err); // DHT11
    return; // DHT11
  }

  Serial.print((int)temperature); Serial.print(" *C, "); // DHT11
  Serial.print((int)humidity); Serial.println(" H"); // DHT11

  Homey.setCapabilityValue("measure_temperature", (int) temperature); // DHT11
  Homey.setCapabilityValue("measure_humidity", (int) humidity); // DHT11

}
void ldrloop() {
    wifi();
  Homey.loop();
  Serial.print("LDR waarde: ");
  Serial.print(analogRead( LDRsensor));
  Serial.println("");
  Homey.setCapabilityValue("measure_luminance", analogRead( LDRsensor));
  delay(1000); // wacht 1 minuut 60000 ms
}
void loop(){ // Beide
dhtloop();    //makes two separate voids, one per original code
co2loop();      //akes two separate voids, one per original code
ldrloop();      //akes two separate voids, one per original code
}

4. Test de metingen via de seriële monitor

Open na het uploaden de Seriële Monitor in Arduino IDE via Hulpmiddelen > Seriële Monitor of met de sneltoets CTRL+SHIFT+M. Zo kun je direct controleren of de CO₂-waarden, DHT11-metingen en LDR-waarde netjes binnenkomen.

5. Koppel de sensor aan Homey

Zodra de code draait, kun je de Homeyduino sensor in Homey toevoegen. Daarna worden de capabilities voor CO₂, temperatuur, luchtvochtigheid en licht beschikbaar in je slimme woning. De bron verwijst daarnaast naar een aparte handleiding voor het koppelen van Homeyduino sensoren in Homey 2.0.

Integratie met Homey

De kracht van dit project zit niet alleen in het meten, maar vooral in wat je daarna met de data kunt doen. Via Homeyduino worden de sensorgegevens als capabilities doorgestuurd naar Homey, zodat je ze kunt uitlezen in Homey Inzichten en als voorwaarde of trigger in flows kunt gebruiken.

Daardoor kun je de multi-sensor op meerdere manieren praktisch inzetten in huis, bijvoorbeeld zo:

  • Automatisch ventileren wanneer de CO₂-concentratie binnenshuis te hoog wordt.
  • Het verloop van luchtvochtigheid volgen om droge of juist te vochtige lucht sneller te signaleren.
  • Lichtmeting gebruiken als extra voorwaarde in flows, bijvoorbeeld in combinatie met tijd of aanwezigheid.

Praktisch gebruik

Een van de meest praktische toepassingen uit de bron is de koppeling met mechanische ventilatie. In combinatie met een geschikt systeem, zoals een mechanische ventilatie-oplossing die met Homey te koppelen is, kun je de gemeten CO₂-waarde gebruiken om de ventilatie automatisch te starten. Zo werkt de sensor niet alleen als meetinstrument, maar ook als onderdeel van een slimmer en gezonder binnenklimaat.

Aandachtspunten

  • Vul in de sketch nog zelf je WiFi-gegevens in bij de SSID- en wachtwoordvelden.
  • De broncode bevat ook een UART-aansluiting voor de MH-Z19B, maar in dit project wordt de CO₂ sensor uitgelezen via PWM.
  • Zorg in Arduino IDE dat het juiste board is geselecteerd en upload de code volgens de bron op 9600 baud.

Conclusie

Met een Wemos D1 Mini, een MH-Z19B, een DHT11 en een LDR bouw je voor relatief weinig geld een verrassend bruikbare multi-sensor. Je meet meerdere waarden tegelijk, krijgt meer inzicht in je binnenklimaat en kunt de data direct inzetten in Homey. Juist die combinatie van betaalbaarheid, praktische toepasbaarheid en uitbreidbaarheid maakt dit een sterk Homeyduino project.
