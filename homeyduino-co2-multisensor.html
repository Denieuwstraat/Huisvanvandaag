Bouw je eigen CO₂ multi-sensor met Homeyduino

Met een MH-Z19B, DHT11, LDR en een Wemos D1 Mini bouw je zelf een betaalbare multi-sensor die CO₂, temperatuur, luchtvochtigheid en licht meet en die je meteen kunt gebruiken in Homey.

Categorie: Binnenklimaat Platform: Homey Hardware: MH-Z19B + DHT11 + LDR + Wemos D1 Mini

Een goed binnenklimaat draait om meer dan alleen temperatuur. Juist de combinatie van CO₂, luchtvochtigheid en licht geeft een veel completer beeld van hoe prettig en gezond een ruimte werkelijk is.

Met dit project bouw je daarom niet zomaar een losse CO₂ sensor, maar een complete multi-sensor die meerdere waarden tegelijk meet en via Homeyduino doorstuurt naar Homey. Daarmee krijg je niet alleen meer inzicht, maar ook directe mogelijkheden om slimmer te automatiseren.

Wat ga je bouwen?

Je bouwt een multi-sensor op basis van een Wemos D1 Mini, een MH-Z19B CO₂ sensor, een DHT11 voor temperatuur en luchtvochtigheid en een LDR voor lichtmeting. Via Homeyduino stuur je de meetwaarden door naar Homey, zodat je ze kunt volgen en gebruiken in flows.

  • Meerdere waarden meten → De sensor combineert CO₂, temperatuur, luchtvochtigheid en licht in één compacte opstelling.
  • Automatiseren met Homey → De meetwaarden worden zichtbaar in Homey en zijn bruikbaar als trigger of voorwaarde in flows.

Het resultaat is een betaalbare zelfbouwsensor die je smart home niet alleen slimmer maakt, maar vooral nuttiger in het dagelijks gebruik.

Waarom is dit nuttig?

Een goede luchtvochtigheid heeft veel invloed op comfort en gezondheid. Een te lage luchtvochtigheid kan zorgen voor droge huid en keel, branderige ogen, gebarsten lippen, hoofdpijn, vermoeidheid en concentratieproblemen. Ook materialen in huis kunnen eronder lijden, zoals houten kozijnen, vloeren en meubels die kunnen krimpen of scheuren.

Een te hoge luchtvochtigheid brengt weer andere problemen met zich mee. Denk aan een toename van bacteriën en schimmels in huis, het uitzetten of rotten van houten meubels en kozijnen, warmteklachten doordat het lichaam moeilijker warmte afvoert en hogere stookkosten omdat vochtige lucht meer energie kost om op te warmen.

Ook een te hoge CO₂-concentratie binnenshuis is niet wenselijk. Dat kan zich onder meer uiten in een slaperig of lamlendig gevoel. Volgens de aangeleverde informatie ligt een acceptabel CO₂-niveau binnenshuis ergens tussen de 600 en 800 ppm. Vanaf 1000 ppm is het wenselijk om te ventileren, omdat dit al invloed heeft op je gezondheid.

Benodigdheden

  • D1 Mini NodeMCU met wifi en 5V
  • Micro USB-oplader
  • MH-Z19B CO₂ sensor
  • LDR sensor
  • DHT11 sensor
  • Homey met de Homeyduino-app geïnstalleerd
  • Een computer of laptop met Arduino IDE, NodeMCU Flasher en Homeyduino om alles eenmalig te configureren

Waarom zelf bouwen?

Er zijn online veel kant-en-klare CO₂ meters te vinden, maar die lopen qua prijs al snel op. Volgens de aangeleverde informatie betaal je voor alleen een CO₂ meter al gauw tussen de € 100 en € 399. Er worden ook goedkopere opties genoemd, zoals een eenvoudige CO₂ meter rond de € 35 en een uitgebreidere luchtkwaliteitsmeter rond de € 73.

Met losse onderdelen ziet het plaatje er anders uit. De MH-Z19B sensor is rond de € 20 te vinden, en in combinatie met een LDR, een DHT11 en een Wemos D1 kom je uit op een bedrag rond de € 30 voor een multi-sensor die meerdere waarden meet en ook nog met je smart home kan communiceren.

Stap-voor-stap uitleg

1. Sluit de sensoren aan

Volg het aansluitschema en sluit de verschillende sensoren aan op de Wemos D1 Mini. In deze opstelling wordt de DHT11 aangesloten op D4, de LDR op A0 en de MH-Z19B op D2. In de sketch staat daarnaast ook een UART-aansluiting voor de CO₂ sensor, maar in deze situatie wordt de sensor alleen uitgelezen via PWM.

  • DHT11 → D4
  • LDR → A0
  • MH-Z19B → D2

2. Bereid de software voor

Installeer Arduino IDE, NodeMCU Flasher en Homeyduino op je computer. Controleer daarna of in Arduino IDE het juiste board is geselecteerd voordat je begint met uploaden.

3. Upload de code

Vul in de sketch je eigen wifi-gegevens in en upload de code via Arduino IDE op 9600 baud naar de Wemos D1 Mini. De sensor meldt zich vervolgens in Homeyduino aan met capabilities voor luchtvochtigheid, temperatuur, CO₂ en licht.

// Code for Homeyduino made by Smart Home Blog https://huisvanvandaag.nl. 
// Take a look at my site for more Homeyduino en other Smart Home projects.

#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <Homey.h>
#include <SimpleDHT.h>
#include <SoftwareSerial.h>
#include <MHZ.h>

#define PIN_DHT D4 // DHT11 
SimpleDHT11 dht11; // DHT11

#define CO2_IN D2 // D2 19 // Co2 
#define MH_Z19_RX D6  // Co2
#define MH_Z19_TX D5  // Co2 
MHZ co2(MH_Z19_RX, MH_Z19_TX, CO2_IN, MHZ19B); // Co2

unsigned long previousMillis = 0; // DHT11
const unsigned long interval = 10000; //Interval in milliseconds // DHT11

int LDRsensor = A0; // LDR

void wifi() {
  if (WiFi.status() != WL_CONNECTED) {
    WiFi.begin("<SSID>", "<PASSWORD>"); // Enter WiFi netwerk and password 
    uint8_t timeout = 30;
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
      if (timeout < 1) break;
    }
    if (WiFi.status() == WL_CONNECTED) {
      Serial.print("Connected to WiFi! (");
      Serial.print(WiFi.localIP());
      Serial.println(")");
    }
  }
}

void setup() { // DHT11
  Serial.begin(9600);
  Homey.begin("LDR-DHT11-Co2 Multi-sensor");
  Homey.setClass("sensor");
  Homey.addCapability("measure_humidity"); // DHT11
  Homey.addCapability("measure_temperature"); // DHT11
  Homey.addCapability("measure_co2"); // Co2 
  pinMode(CO2_IN, INPUT); // Co2
  Homey.addCapability("measure_luminance"); // LDR
}

void co2loop() { // void voor Co2
  wifi(); // Beide
  Homey.loop(); // Beide
  int ppm_pwm = co2.readCO2PWM();
  Serial.print("PPMpwm: ");
  Serial.print(ppm_pwm);
  Homey.setCapabilityValue("measure_co2", (int) ppm_pwm); 

  Serial.println("\n------------------------------");
  delay(5000);
}

void dhtloop() { // void voor DHT11
  wifi(); // Beide
  Homey.loop(); // Beide
  unsigned long currentMillis = millis(); // DHT11
  if(currentMillis - previousMillis > interval) { // DHT11
    previousMillis = currentMillis; // DHT11
    updateSensor(); // DHT11
  }
}

void updateSensor() { // DHT11
  byte temperature = 0; // DHT11
  byte humidity = 0; // DHT11
  int err = SimpleDHTErrSuccess; // DHT11
  if ((err = dht11.read(PIN_DHT, &temperature, &humidity, NULL)) != SimpleDHTErrSuccess) { // DHT11
    Serial.print("Read DHT11 failed, err="); Serial.println(err); // DHT11
    return; // DHT11
  }

  Serial.print((int)temperature); Serial.print(" *C, "); // DHT11
  Serial.print((int)humidity); Serial.println(" H"); // DHT11

  Homey.setCapabilityValue("measure_temperature", (int) temperature); // DHT11
  Homey.setCapabilityValue("measure_humidity", (int) humidity); // DHT11
}

void ldrloop() {
  wifi();
  Homey.loop();
  Serial.print("LDR waarde: ");
  Serial.print(analogRead(LDRsensor));
  Serial.println("");
  Homey.setCapabilityValue("measure_luminance", analogRead(LDRsensor));
  delay(1000); // wacht 1 minuut 60000 ms
}

void loop(){ // Beide
  dhtloop();
  co2loop();
  ldrloop();
}

4. Test de metingen

Nu het is gelukt om de code te uploaden, kun je de sensor meteen testen. Open hiervoor in Arduino IDE de Seriële Monitor via Hulpmiddelen en dan Seriële Monitor, of gebruik de sneltoets CTRL+SHIFT+M. Zo controleer je direct of de waarden voor CO₂, temperatuur, luchtvochtigheid en licht netjes binnenkomen.

5. Koppel de sensor aan Homey

Daarna kun je de Homeyduino sensor toevoegen aan Homey. De handleiding daarvoor komt als apart tutorial-artikel beschikbaar. Zodra de sensor gekoppeld is, worden de verschillende meetwaarden zichtbaar in Homey en kun je ze gebruiken in je automatiseringen.

Integratie met Homey

De kracht van dit project zit niet alleen in het meten, maar vooral in wat je daarna met de data kunt doen. Via Homeyduino stuur je de waarden door naar Homey, zodat je ze kunt volgen via Homey Inzichten en als trigger of voorwaarde kunt gebruiken in flows.

Daarmee wordt deze multi-sensor direct bruikbaar voor praktische automatiseringen, zoals:

  • automatisch ventileren wanneer de CO₂-concentratie binnenshuis te hoog wordt
  • het verloop van luchtvochtigheid volgen om te droge of juist te vochtige lucht sneller te signaleren
  • lichtmeting gebruiken als extra voorwaarde in flows

Praktisch gebruik

Helemaal interessant wordt het wanneer je deze sensor koppelt aan mechanische ventilatie. In de aangeleverde toepassing gebeurt dat met een systeem van Itho Daalderop dat via de Spider app aan Homey gekoppeld kan worden. Wanneer de CO₂-concentratie binnenshuis te hoog wordt, kan een flow automatisch de mechanische ventilatie starten. Op die manier gebruik je de sensor niet alleen als meetinstrument, maar als actief onderdeel van een gezonder binnenklimaat.

Aandachtspunten

  • Vul in de sketch nog zelf je wifi-gegevens in bij de SSID- en wachtwoordvelden.
  • In deze opstelling wordt de CO₂ sensor uitgelezen via PWM, ook al staat de UART-aansluiting wel in de sketch vermeld.
  • Controleer altijd of in Arduino IDE het juiste board is geselecteerd en upload de code op 9600 baud.

Conclusie

Met een MH-Z19B, DHT11, LDR en een Wemos D1 Mini bouw je met beperkte middelen een verrassend bruikbare multi-sensor. Je meet meerdere waarden tegelijk, krijgt meer grip op je binnenklimaat en kunt de data direct inzetten in Homey. Juist die combinatie van lage kosten, praktische inzet en slimme integratie maakt dit een sterk DIY-project voor iedereen die meer uit zijn smart home wil halen.
