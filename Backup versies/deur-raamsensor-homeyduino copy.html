Bouw je eigen deur- of raamsensor met Homeyduino

Met een eenvoudige MC-38 deur- of raamsensor en een ESP8266-board bouw je zelf een bedrade sensor die direct bruikbaar is in Homey voor flows, meldingen en praktische automatiseringen in huis.

Categorie: Beveiliging & automatisering Platform: Homey Hardware: MC-38 + ESP8266 / Wemos D1 Mini

Een deur- of raamsensor is zo’n onderdeel dat eenvoudig oogt, maar in de praktijk verrassend veel toevoegt aan een smart home. Zodra je weet of een deur of raam open of dicht is, kun je daar allerlei logische acties aan koppelen.

Denk aan verlichting die automatisch aangaat, een melding wanneer een raam nog open staat terwijl het begint te regenen of een eenvoudige alarmfunctie wanneer een deur onverwacht wordt geopend. Met Homeyduino bouw je zo’n sensor zelf, tegen lage kosten en volledig geïntegreerd in Homey.

Wat ga je bouwen?

Je bouwt een bedrade deur- of raamsensor op basis van een MC-38 contactsensor en een ESP8266-board, zoals een NodeMCU of Wemos D1 Mini. Via Homeyduino stuur je de open/dicht-status door naar Homey, zodat de sensor zichtbaar wordt in Homey en bruikbaar is in flows.

  • Status meten → De sensor bepaalt of een deur of raam open of gesloten is.
  • Automatiseren met Homey → De status is te gebruiken als trigger voor verlichting, meldingen, alarmfuncties of andere flows.

Het resultaat is een eenvoudige maar praktische zelfbouwsensor die goed laat zien hoeveel je met een klein Homeyduino-project al kunt bereiken.

Kant-en-klaar of zelf bouwen?

Voor Homey zijn online genoeg kant-en-klare deur- en raamsensoren te vinden. Het grote voordeel daarvan is dat ze direct bruikbaar zijn en meestal draadloos werken. Dat kan juist handig zijn op plekken waar je geen voeding beschikbaar hebt.

De keerzijde is dat veel van die sensoren op batterijen werken. Als je thuis al veel batterijsensoren gebruikt, kan dat op termijn minder praktisch worden. Juist daarom is een bedrade zelfbouwvariant interessant: je bouwt voor weinig geld een sensor op netspanning die je volledig naar eigen wens integreert met Homey.

Benodigdheden

  • ESP8266 NodeMCU of Wemos D1 Mini
  • USB-C oplader
  • Breadboard
  • MC-38 deur- of raamsensor
  • Homey met de Homeyduino-app geïnstalleerd
  • Een computer of laptop met Arduino IDE, NodeMCU Flasher en Homeyduino om alles eenmalig te configureren

Waarom dit project financieel interessant is

Wie deze sensor zelf wil bouwen, kan de benodigde onderdelen relatief goedkoop vinden. In de aangeleverde informatie worden onder meer een ESP8266 NodeMCU, een Wemos D1 Mini, een klein breadboard en een MC-38 deur- of raamcontact genoemd als voordelige onderdelen om mee te starten.

Daarmee blijft dit project niet alleen technisch overzichtelijk, maar ook financieel laagdrempelig. Juist voor dit soort eenvoudige sensoren is zelfbouw daardoor een interessante optie.

Stap-voor-stap uitleg

1. Sluit de sensor aan

Volg het aansluitschema om de MC-38 sensor op je board aan te sluiten. In de broninformatie wordt een ESP8266 NodeMCU als voorbeeld genoemd, maar op een Wemos D1 Mini werkt dit nagenoeg hetzelfde. In de code wordt de sensor aangesloten op pin D2.

  • MC-38 sensor → D2
  • Board → ESP8266 NodeMCU of Wemos D1 Mini
  • Ingestelde modus → INPUT_PULLUP

2. Bereid de software voor

Installeer Arduino IDE, NodeMCU Flasher en Homeyduino op je computer. Controleer daarna of in Arduino IDE het juiste board is geselecteerd. Werkt je ESP8266-board niet goed, dan kun je volgens de aangeleverde informatie proberen het eerst te flashen met NodeMCU Flasher.

3. Upload de code

Vul in de sketch je eigen wifi-gegevens in en upload de code op 9600 baud. De sensor wordt in Homey aangemeld met de capability alarm_contact, zodat de open- of dichtstatus zichtbaar en bruikbaar wordt in flows.

// Code aangepast voor Homeyduino door Domoticablog https://huisvanvandaag.nl. 
// Kijk op de site voor meer Homeyduino en andere Smart Home gerelateerde posts.

#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <Homey.h>

const int DOOR_SENSOR_PIN = D2; // ESP8266 pin D2 verbonden met deur sensor's pin

int doorState;

void wifi() {
  if (WiFi.status() != WL_CONNECTED) {
    WiFi.begin("<SSID>", "<PASSWORD>"); // Vul hier je WiFi netwerk en wachtwoord in 
    uint8_t timeout = 30;
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
      if (timeout<1) break;
    }
    if (WiFi.status() == WL_CONNECTED) {
      //Print IP address
      Serial.print("Verbonden met WiFi! (");
      Serial.print(WiFi.localIP());
      Serial.println(")");
    }
  }
}

void setup() {
  Serial.begin(9600);
  Homey.begin("Deur sensor");
  Homey.setClass("sensor");
  Homey.addCapability("alarm_contact");
  pinMode(DOOR_SENSOR_PIN, INPUT_PULLUP);
}

void loop() {
  wifi();
  Homey.loop();
  doorState = digitalRead(DOOR_SENSOR_PIN);
  delay(3000);
  if (doorState == HIGH) {
    Serial.println("The door is open");
    Homey.setCapabilityValue("alarm_contact", (true)); 
  } else {
    Serial.println("The door is closed");
    Homey.setCapabilityValue("alarm_contact", (false)); 
  }
}

4. Test de sensor via de seriële monitor

Open na het uploaden de Seriële Monitor in Arduino IDE via Hulpmiddelen en daarna Seriële Monitor, of gebruik de sneltoets CTRL+SHIFT+M. Vervolgens kun je direct zien welke status de sensor uitleest.

Volgens de aangeleverde code verschijnen in de monitor de meldingen “The door is open” en “The door is closed”. Gebruik dit vooral als controle of de sensor consequent reageert wanneer je de twee delen tegen elkaar houdt of juist van elkaar verwijdert.

5. Koppel de sensor aan Homey

Daarna kun je het Homeyduino-project koppelen aan Homey. De handleiding daarvoor komt als apart tutorial-artikel beschikbaar. Zodra de sensor in Homey staat, kun je de status gebruiken in flows en meldingen.

Integratie met Homey

Door de deur- of raamsensor aan Homey te koppelen kun je meer doen dan alleen de status uitlezen. De sensor wordt een praktisch startpunt voor allerlei slimme scenario’s in huis.

Denk bijvoorbeeld aan:

  • verlichting automatisch inschakelen wanneer een deur of raam wordt geopend
  • een melding krijgen wanneer een raam nog open staat terwijl het gaat regenen
  • Homey gebruiken als eenvoudig persoonlijk alarmsysteem

Praktisch gebruik

Juist omdat deze sensor zo eenvoudig is, zijn er veel praktische toepassingen te bedenken. Denk aan een kastdeur, schuurdeur, raam of buitendeur. De status alleen al is waardevol, maar in combinatie met Homey wordt zo’n eenvoudige contactsensor ineens een nuttig onderdeel van je bredere automatisering.

Tegelijkertijd zit daar ook meteen de praktische grens: het is niet heel handig om voor ieder raam of iedere deur een apart Arduino-board te plaatsen. Juist daarom is dit project vooral interessant als losse sensor, als leerproject of als basis voor een latere gecombineerde oplossing.

Aandachtspunten

  • Gebruik in de sketch je eigen wifi-gegevens voordat je de code uploadt.
  • Controleer in Arduino IDE altijd of het juiste board is geselecteerd.
  • Een bedrade oplossing is niet in elke situatie de meest praktische keuze; soms blijft een draadloze sensor logischer.

Conclusie

Met een MC-38 sensor, een ESP8266-board en Homeyduino bouw je met beperkte middelen een goed werkende bedrade deur- of raamsensor. Het project is eenvoudig, goedkoop en direct bruikbaar in Homey. Juist doordat je er zoveel verschillende flows aan kunt koppelen, is dit een klein project met verrassend veel praktische waarde.
