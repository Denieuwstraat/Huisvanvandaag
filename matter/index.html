Firmware installer

HVV Matter Sensor

v0.2.1

Sluit de ESP32 aan met een USB-datakabel en installeer de firmware rechtstreeks vanuit je browser.

  • Gebruik Google Chrome of Microsoft Edge op een computer.
  • Gebruik een USB-kabel die ook data kan overdragen.
  • Sluit andere programma’s die de seriële poort gebruiken.
Deze browser ondersteunt de webinstaller niet. Gebruik Google Chrome of Microsoft Edge. Open deze installer via HTTPS of localhost.
Let op: bij een nieuwe installatie wordt het flashgeheugen gewist. Bestaande Matter- en wifi-instellingen gaan daardoor verloren.
