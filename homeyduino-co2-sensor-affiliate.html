Bouw je eigen slimme CO₂ sensor met Homeyduino

Met een MH-Z19B sensor, een Wemos D1 Mini en Homeyduino bouw je zelf een slimme CO₂ sensor die je binnenklimaat bewaakt en direct bruikbaar is in Homey-flows.

Categorie: Binnenklimaat Platform: Homey Hardware: MH-Z19B + Wemos D1 Mini

Waarom dit project leuk én nuttig is

✓
Betaalbare zelfbouw
Je bouwt deze CO₂ sensor met beperkte middelen, zonder meteen uit te komen op kant-en-klare meters van honderden euro’s.
✓

Een gezond binnenklimaat krijgt steeds meer aandacht, en dat is logisch. Zeker in goed geïsoleerde woningen blijft de lucht langer hangen, waardoor CO₂ zich binnenshuis kan ophopen. Juist daarom is het interessant om die waarde niet alleen af en toe te meten, maar continu te volgen.

Met dit project bouw je zelf een slimme CO₂ sensor die meet, logt en samenwerkt met Homey. Daarmee zie je niet alleen hoe de luchtkwaliteit zich door de dag heen ontwikkelt, maar kun je ook automatiseren zodra ventileren echt nodig is.

Wat ga je bouwen?

Je bouwt een CO₂ sensor op basis van de MH-Z19B en koppelt die via Homeyduino aan Homey. De sensor leest de CO₂-waarde uit via PWM en stuurt die door als meetwaarde, zodat je de concentratie kunt volgen en gebruiken in automatiseringen.

  • CO₂ meten → De MH-Z19B meet de concentratie koolstofdioxide in ppm en geeft die waarde door aan de microcontroller.
  • Automatiseren met Homey → De gemeten waarde wordt zichtbaar in Homey en kan daarna worden gebruikt als trigger voor flows en ventilatie-aansturing.

Het resultaat is een compacte en betaalbare sensoroplossing waarmee je jouw smart home niet alleen slimmer, maar ook praktischer maakt voor dagelijks gebruik.

Benodigdheden

  • Wemos D1 Mini of NodeMCU met wifi en 5V
  • Micro USB-oplader
  • MH-Z19B CO₂ sensor
  • Homey met de Homeyduino-app geïnstalleerd
  • Een computer of laptop met Arduino IDE, NodeMCU Flasher en Homeyduino om alles eenmalig te configureren

Stap-voor-stap uitleg

1. Sluit de sensor aan

Volg het aansluitschema en verbind de MH-Z19B met de Wemos D1 Mini. In deze opstelling wordt de sensor uitgelezen via PWM. In de sketch staat ook de UART-aansluiting, maar in deze situatie wordt die niet gebruikt voor de meting zelf.

  • PWM → D2
  • 5V → 5V
  • G → G

2. Bereid de software voor

Installeer Arduino IDE, NodeMCU Flasher en Homeyduino op je computer. Controleer daarna of in Arduino IDE het juiste board is geselecteerd voordat je begint met uploaden.

3. Upload de code

Vul in de sketch je eigen wifi-gegevens in en upload de code op 9600 baud naar de Wemos D1 Mini. De sensor wordt vervolgens als Homeyduino-sensor aangemeld met de capability measure_co2.

// Code for Homeyduino made by Smart Home Blog https://huisvanvandaag.nl.
// Take a look at my site for more Homeyduino en other Smart Home projects.

#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <SoftwareSerial.h>
#include <MHZ.h>
#include <Homey.h>

#define CO2_IN D2
#define MH_Z19_RX D6
#define MH_Z19_TX D5

MHZ co2(MH_Z19_RX, MH_Z19_TX, CO2_IN, MHZ19B);

void wifi() {
  if (WiFi.status() != WL_CONNECTED) {
    WiFi.begin("<SSID>", "<PASSWORD>");
    uint8_t timeout = 30;
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
      if (timeout < 1) break;
    }
    if (WiFi.status() == WL_CONNECTED) {
      Serial.print("Verbonden met WiFi! (");
      Serial.print(WiFi.localIP());
      Serial.println(")");
    }
  }
}

void setup() {
  Serial.begin(9600);
  Homey.begin("Co2 sensor");
  Homey.setClass("sensor");
  Homey.addCapability("measure_co2");
  pinMode(CO2_IN, INPUT);
  delay(100);
}

void loop() {
  wifi();
  Homey.loop();

  int ppm_pwm = co2.readCO2PWM();
  Serial.print("PPMpwm: ");
  Serial.print(ppm_pwm);
  Homey.setCapabilityValue("measure_co2", (int) ppm_pwm);

  Serial.println("\n------------------------------");
  delay(5000);
}

4. Test de metingen via de seriële monitor

Open in Arduino IDE de seriële monitor via Hulpmiddelen → Seriële Monitor of met CTRL+SHIFT+M. Houd er rekening mee dat de sensor bij de eerste start enkele minuten nodig kan hebben om op te warmen. Verschijnt er niet direct een waarde, wacht dan nog even.

5. Controleer en kalibreer je gevoel voor de waardes

Een praktische controle is om de sensor ook even buiten te laten meten wanneer het ruim boven het vriespunt is. In de broninformatie wordt een buitenconcentratie van 417 ppm genoemd voor 2020, terwijl in de eigen metingen buiten ongeveer 530 ppm werd afgelezen. Zo krijg je een eerste indruk of jouw waardes logisch ogen.

Integratie met Homey

Zodra de sensor actief is, kun je de CO₂-waarde in Homey gebruiken als gewone meetwaarde. Daardoor wordt de sensor zichtbaar in Homey en kun je het verloop van de metingen volgen via Homey Insights.

Dat maakt deze zelfbouwsensor direct bruikbaar in praktische automatiseringen, zoals:

  • een flow starten zodra de CO₂-waarde boven een zelfgekozen grens komt
  • het verloop van de luchtkwaliteit per dag volgen via Homey Insights
  • mechanische ventilatie automatisch naar een hogere stand schakelen bij een te hoge CO₂-concentratie

Praktisch gebruik

In de beschreven setup thuis is de CO₂ sensor gekoppeld aan de mechanische ventilatie van Itho Daalderop via de Spider thermostaat en gateway. De ventilatie draait daar al op gezette tijden, maar als de CO₂-waarde boven 1000 ppm uitkomt terwijl de ventilatie niet actief is, schakelt Homey alsnog de booststand in voor 30 minuten. Daarmee wordt ventileren niet alleen slimmer, maar ook veel gerichter.

Aandachtspunten

  • De sensor kan bij de eerste start drie minuten of langer nodig hebben voordat er bruikbare waardes verschijnen.
  • In deze opstelling wordt de meting via PWM uitgelezen, ook al staan de UART-aansluitingen wel in de sketch vermeld.
  • Controleer altijd of in Arduino IDE het juiste board is geselecteerd en upload de code op 9600 baud.

Conclusie

Met een MH-Z19B, een Wemos D1 Mini en Homeyduino bouw je een verrassend bruikbare CO₂ sensor voor een relatief laag bedrag. Je krijgt inzicht in je binnenklimaat, kunt metingen terugzien in Homey en voegt direct een slimme trigger toe voor ventilatie of andere flows. Juist die combinatie van lage kosten, praktische inzet en Homey-integratie maakt dit een sterk DIY-project voor iedereen die slimmer wil wonen.
