Bouw je eigen ‘Clapper’ switch met Homeyduino

Wie herinnert zich nog de ‘Clapper’? Deze opvallende Amerikaanse uitvinding uit de jaren 80 en 90 werkte op een verrassend simpele manier: klappen in je handen en het licht ging aan of uit.

Voor die tijd was dat een futuristisch stukje domotica. Tegenwoordig zijn smart homes een stuk geavanceerder, maar het idee achter de Clapper is nog steeds leuk én praktisch.

Met behulp van Homey, Homeyduino en een eenvoudige geluidssensor kun je een moderne versie bouwen die niet alleen lampen schakelt, maar ook complete Homey flows kan starten.

Zelf gebruik ik er inmiddels één op de slaapkamer. Wanneer ik twee keer klap voordat ik ga slapen, schakelt Homey automatisch alle verlichting uit.

Waarom een clap switch nog steeds handig is

Hoewel het concept oud is, zijn er verrassend veel moderne toepassingen:

  • Verlichting uitschakelen wanneer je al in bed ligt
  • Een “alles uit” flow starten wanneer je het huis verlaat
  • Lampen bedienen wanneer je handen vol zijn
  • Een leuke smart-home interactie voor kinderen of gasten

Het mooie is dat een simpele geluidssensor via Homeyduino kan worden gekoppeld aan vrijwel elke automatisering die Homey ondersteunt.

Benodigdheden

  • Wemos D1 Mini (ESP8266)
  • Geluidssensor voor Arduino
  • Micro-USB voeding
  • Homey Smart Home Hub met Homeyduino app
  • Arduino IDE

Deze onderdelen zijn goedkoop en eenvoudig te verkrijgen. Vaak kosten ze samen minder dan een standaard smart-home sensor.

Aansluitschema

Sluit de geluidssensor als volgt aan op de Wemos D1 Mini:

Sensor Wemos D1 Mini pin
OUT D2
VCC 5V
GND GND

Arduino IDE installeren

Installeer eerst de Arduino IDE. Vervolgens moeten enkele libraries worden toegevoegd.

Homeyduino library installeren

Ga naar:

Schets → Bibliotheek gebruiken → Bibliotheken beheren

Zoek vervolgens op Homeyduino en installeer deze library.

Zoek daarna ook naar ESP8266 en installeer deze eveneens.

Wemos board installeren

Ga naar:

Hulpmiddelen → Board → Boardbeheer

Zoek naar Wemos D1 Mini en installeer het board.

Homeyduino clap switch code

Open nu een nieuw Arduino project en vervang de standaard tekst door onderstaande code.

Let op: vervang <SSID> en <PASSWORD> door je eigen wifi gegevens.

#include <ESP8266WiFi.h> #include <WiFiClient.h> #include <Homey.h> int soundSensor = D2; int claps = 0; long detectionSpanInitial = 0; long detectionSpan = 0; boolean ClapState = false; void wifi() { if (WiFi.status() != WL_CONNECTED) { WiFi.begin("<SSID>", "<PASSWORD>"); uint8_t timeout = 30; while (WiFi.status() != WL_CONNECTED) { delay(500); if (timeout<1) break; } } } void setup() { Serial.begin(9600); Homey.begin("Sound sensor"); Homey.setClass("sensor"); pinMode(soundSensor, INPUT); } void loop() { wifi(); Homey.loop(); int sensorState = digitalRead(soundSensor); if (sensorState == 0) { if (claps == 0) { detectionSpanInitial = detectionSpan = millis(); claps++; } else if (claps > 0 && millis()-detectionSpan >= 50) { detectionSpan = millis(); claps++; } } if (millis()-detectionSpanInitial >= 400) { if (claps == 2) { if (!ClapState) { ClapState = true; Homey.trigger("clap_on",true); } else { ClapState = false; Homey.trigger("clap_off",false); } } claps = 0; } }

Uploaden naar de Wemos

Controleer eerst of het juiste board geselecteerd is:

LOLIN (Wemos) D1 R2 & Mini

Klik daarna op Upload om de code naar het board te sturen.

Testen via de seriële monitor

Open de seriële monitor via:

Hulpmiddelen → Seriële monitor

Wanneer je twee keer klapt zou de sensor een trigger moeten detecteren.

Probeer ook eens één of drie keer te klappen. De code is zo geschreven dat deze alleen reageert op twee snelle klappen om valse triggers te voorkomen.

Koppelen aan Homey

Open de Homey app en voeg een nieuw apparaat toe:

  • Apparaten
  • Homeyduino
  • Arduino
  • Installeren

Kies vervolgens de sensor die je zojuist hebt geconfigureerd.

Homey flow instellen

Gebruik in Homey een Boolean trigger met:

  • clap_on
  • clap_off

Hiermee kun je flows maken zoals:

  • Alle lampen uitschakelen
  • Nachtmodus activeren
  • Een specifieke lamp schakelen
