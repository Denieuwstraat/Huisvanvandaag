Bouw je eigen ‘Clapper’ switch met Homeyduino

De originele Clapper was ooit een bijna futuristische huiskamergadget. Met een Wemos D1 Mini, een geluidssensor en Homeyduino bouw je een moderne versie die twee klappen herkent en die direct inzetbaar is als trigger voor slimme Homey-flows.

Categorie: DIY Platform: Homey Hardware: Wemos D1 Mini + geluidssensor

Wie hem nog kent, herinnert zich vooral het idee: in je handen klappen en een lamp gaat aan. De originele Clapper uit de jaren 80 en 90 voelde destijds bijna als sciencefiction voor de woonkamer. Juist daarom is het zo leuk om dat oude concept opnieuw tot leven te brengen met moderne smart-home techniek.

Met dit project maak je een geluidsgestuurde sensor die twee klappen herkent en die direct koppelt aan Homey. Daarmee bedien je niet alleen één lamp, maar kun je complete flows, scènes of meerdere apparaten tegelijk activeren.

Wat ga je bouwen?

Je bouwt een eenvoudige Homeyduino-opstelling die twee klappen achter elkaar detecteert. Op basis daarvan schakelt het systeem tussen twee toestanden:

  • clap_on → bij twee klappen wordt de eerste trigger geactiveerd
  • clap_off → bij de volgende twee klappen wordt de tweede trigger geactiveerd

Daardoor is deze Clapper niet alleen een speelse schakelaar, maar ook een verrassend praktische ingang voor slimme automatisering in huis.

Benodigdheden

  • Wemos D1 Mini of NodeMCU met wifi en 5V
  • Geluidssensor voor Arduino / ESP8266
  • USB-C-voeding
  • Homey met de Homeyduino app
  • Arduino IDE

Voorkom gepruts: bestel meteen de juiste onderdelen

Dit zijn precies de producten die dit project soepel laten draaien. Scheelt uitzoeken, testen en drie keer opnieuw bestellen.

Stap-voor-stap uitleg

1. Sluit de geluidssensor aan

Sluit de geluidssensor aan op de Wemos D1 Mini met deze verbindingen:

  • OUT → D2
  • VCC → 5V
  • GND → GND

2. Installeer Arduino IDE en de benodigde libraries

Installeer Arduino IDE en voeg de libraries Homeyduino en ESP8266 toe. Kies daarna via Hulpmiddelen → Board → Board Beheer het juiste board voor de Wemos D1 Mini.

3. Upload de code

Gebruik onderstaande code als basis. Vul eerst je eigen wifi-gegevens in bij <SSID> en <PASSWORD>. De code detecteert twee klappen binnen een korte tijdspanne en wisselt daarna tussen een aan- en uitstatus.

#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <Homey.h>

int soundSensor = D2;
int claps = 0;
long detectionSpanInitial = 0;
long detectionSpan = 0;
boolean ClapState = false;

void wifi() {
  if (WiFi.status() != WL_CONNECTED) {
    WiFi.begin("<SSID>", "<PASSWORD>");
    uint8_t timeout = 30;
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
      if (timeout < 1) break;
    }
    if (WiFi.status() == WL_CONNECTED) {
      Serial.print("Connected to WiFi! (");
      Serial.print(WiFi.localIP());
      Serial.println(")");
    }
  }
}

void setup() {
  Serial.begin(9600);
  Homey.begin("Sound sensor");
  Homey.setClass("sensor");
  pinMode(soundSensor, INPUT);
}

void loop() {
  wifi();
  Homey.loop();

  int sensorState = digitalRead(soundSensor);

  if (sensorState == 0) {
    if (claps == 0) {
      detectionSpanInitial = detectionSpan = millis();
      claps++;
    }
    else if (claps > 0 && millis() - detectionSpan >= 50) {
      detectionSpan = millis();
      claps++;
    }
  }

  if (millis() - detectionSpanInitial >= 400) {
    if (claps == 2) {
      if (!ClapState) {
        ClapState = true;
        Serial.println("Licht aan");
        Homey.trigger("clap_on", true);
      }
      else {
        ClapState = false;
        Serial.println("Licht uit");
        Homey.trigger("clap_off", false);
      }
    }
    claps = 0;
  }
}

4. Selecteer het juiste board en upload

Kies in Arduino IDE het board LOLIN (Wemos) D1 R2 & Mini en upload daarna de code naar de Wemos D1 Mini.

5. Test de detectie via de seriële monitor

Open de seriële monitor en klap twee keer achter elkaar. Als alles goed werkt, zie je afwisselend “Licht aan” en “Licht uit”. Test ook bewust met één of drie klappen om te zien hoe stabiel de detectie reageert.

Integratie met Homey

Voeg het apparaat toe via de Homeyduino app in Homey. Gebruik daarna de triggers clap_on en clap_off in je flows om acties te koppelen.

Denk bijvoorbeeld aan:

  • verlichting in de slaapkamer aan of uit
  • een avondmodus activeren
  • meerdere lampen of apparaten tegelijk schakelen

Praktisch gebruik

Een voor de hand liggende toepassing is de slaapkamer: twee klappen en alle verlichting gaat uit. Maar juist de koppeling met Homey maakt dit project interessanter dan de originele Clapper. In plaats van één apparaat kun je een complete flow starten die meerdere acties tegelijk uitvoert.

Aandachtspunten

  • Gebruik duidelijke en unieke namen als je meerdere geluidssensoren inzet.
  • Test de gevoeligheid van de sensor zorgvuldig om ongewenste detecties te beperken.
  • Houd rekening met omgevingsgeluid, omdat dat invloed kan hebben op de werking.

Conclusie

De originele Clapper was ooit een opvallend stukje huisautomatisering. Met deze Homeyduino-versie geef je dat idee een moderne update: eenvoudig om te bouwen, leuk om te testen en direct bruikbaar binnen je smart home. Juist door de koppeling met Homey wordt het meer dan een gimmick en verandert het in een praktische trigger voor automatisering.
